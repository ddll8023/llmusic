## 快速定位

| 需求或问题 | 优先读取文件 | 选择依据 |
|---|---|---|
| 应用启动与生命周期 | `sys_electron/main.ts` | 主进程入口：窗口、托盘、后端子进程、数据库初始化、退出清理 |
| 开发模式一键启动 | `sys_electron/dev-runner.ts` | 按序拉起后端 FastAPI、Vite、Electron 三个进程 |
| 后端服务启动与异常处理 | `backend/app/main.py`、`backend/entry.py` | FastAPI 应用创建、路由注册、统一异常处理；entry 为打包版入口 |
| IPC 通道与渲染进程桥接 | `sys_electron/constants/ipcChannels.ts`、`sys_electron/preload.ts` | 通道名唯一来源；preload 暴露 `window.electronAPI` |
| 本地数据库 | `sys_electron/handlers/data/db.ts`、`handlers/data/Database.ts` | SQLite 连接、WAL、建表 DDL；Database 为各 repo 聚合门面 |
| 本地音乐扫描 | `sys_electron/handlers/scan/MusicScanner.ts` | Worker 线程扫描、增量/全量、进度与取消 |
| 音频播放链路 | `sys_vue/src/core/audio/engine.ts`、`sys_electron/handlers/system/audioProtocol.ts` | 统一音频引擎；`llmusic://` 协议流式播放与转码 |
| 页面视图切换 | `sys_vue/src/App.vue`、`sys_vue/src/store/ui.ts` | 全局视图状态与布局；App 为页面容器 |
| QQ 音乐后端接口 | `backend/app/api/qqmusic.py` | 搜索、歌单、登录、下载元数据全部路由 |
| QQ 音乐前端调用 | `sys_vue/src/api/qqmusic.ts` | axios 封装、统一响应解包、凭证失效联动 |
| 在线歌单缓存 | `sys_electron/handlers/data/onlinePlaylistCacheRepo.ts`、`onlinePlaylistCacheHandlers.ts` | SQLite 缓存读写、清理与 IPC 通道 |
| 登录认证 | `backend/app/services/auth.py` | 二维码登录会话、凭证自动刷新与写盘 |
| 操作日志 | `backend/app/services/operation_log.py`、`sys_vue/src/components/pages/OperationLog.vue` | JSON Lines 落盘、查询/清理 API、自动保留策略、开发者日志页面 |
| 在线下载 | `sys_electron/handlers/download/downloadHandlers.ts` | 单曲/批量下载、并发限流、ID3 标签嵌入 |
| 前端构建 | `sys_vue/vite.config.js`、`sys_vue/package.json` | Vite 配置（端口、后端地址注入）与构建脚本 |
| 打包发布 | `build.bat`、`sys_electron/package.json` | 打包流水线；electron-builder 配置与 extraResources |
