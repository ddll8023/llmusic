# LLMusic 项目结构文档

## 1. 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | Electron | 桌面窗口壳、系统托盘、文件系统访问、子进程管理 |
| 前端框架 | Vue 3 | UI 渲染，Composition API + `<script setup lang="ts">` |
| 前端构建 | Vite 6 | 开发服务器与构建打包 |
| 类型系统 | TypeScript 5 | **全栈渐进迁移，strict 模式**。第一阶段前端 JS→TS（vue-tsc 检查），**第二阶段 Electron 主进程 JS→TS（tsc 编译到 dist-ts/）** |
| 前端状态管理 | Pinia | 全局状态管理，类型化 Store |
| 前端 UI | Font Awesome 4 | 图标库 |
| 前端样式 | Tailwind CSS v4 | 原子化样式，`@tailwindcss/vite` 插件处理 |
| 前端 HTTP | axios | 调用后端 FastAPI 接口（官方搜索/下载） |
| Electron 音频处理 | music-metadata | 读取本地音频元数据 |
| Electron 音频处理 | fluent-ffmpeg + ffmpeg-static + ffprobe-static | 音频解码与转码、封面提取、标签编辑 |
| Electron 音频处理 | node-id3 | MP3/FLAC 音频标签写入（ID3v2.4，含 USLT 歌词/APIC 封面） |
| Electron 本地数据 | lowdb | JSON 文件数据库，管理歌曲/音乐库/歌单/设置 |
| 后端框架 | FastAPI + Uvicorn | RESTful API 服务 |
| 后端序列化 | Pydantic + Pydantic Settings | 请求/响应校验与配置管理 |
| 在线音乐 SDK | qqmusic-api-python | QQ 音乐搜索、歌曲详情、歌单、下载链接、二维码登录 |
| 后端 HTTP | httpx | 解析 QQ 音乐分享链接重定向 + 第三方下载源代理 |
| Python 依赖管理 | uv + pyproject.toml | 虚拟环境与依赖管理，位于 `backend/.venv/` |
| 打包工具 | electron-builder + PyInstaller | 桌面应用打包与 Python 后端打包为 exe |

| 文件 | 说明 |

| `sys_vue/package.json` | 前端依赖：Vue 3、Pinia、axios、Tailwind CSS、TypeScript |

## 3. 启动边界

- 全栈开发启动：`start-dev.bat` 或 `npm run dev`
- 后端独立调试：`npm run dev:backend`
- 仅前端 + Electron：`npm run dev:electron`
- Electron 类型检查：`npm --prefix sys_electron run type-check`
- 前端类型检查：`npm --prefix sys_vue run type-check`
- 后端运行在 `http://127.0.0.1:9752`，前端 Vite 开发服务器在 `http://127.0.0.1:9753`

## 4. 后端架构

后端采用 FastAPI 四层架构，**仅服务官方 QQ 音乐模块**，不参与第三方源系统。

```
API (app/api/) → Services (app/services/) → qqmusic_api (外部 SDK)
   ↓
Schemas (app/schemas/)  ← 数据校验与序列化
Core (app/core/)        ← 配置管理
```

第三方源系统全部在 Electron 主进程中运行，不经过后端。

## 5. 第三方源 / UserAPI 插件系统

### 架构定位

第三方源系统与官方 QQ 音乐模块**完全平行独立**：

```
应用搜索
├── [官方] Tab → FastAPI 后端 → QQ SDK（需登录）
│   └── 搜索/下载/歌词/封面全部由后端提供
│
└── [第三方] Tab → 主进程插件系统
    ├── 内置源（tx/kw/kg/wy/mg）：主进程直接搜索公开 API
    └── UserAPI 脚本：隐藏 BrowserWindow 执行，完全兼容 lx-music 协议
```

### 核心模块

| 模块 | 文件 | 说明 |
|------|------|------|
| 类型定义 | `types/userapi.ts` | SourcePlatform、QualityLevel、ScriptRecord、请求/响应协议 |
| 隐藏窗口 | `handlers/thirdparty/hiddenWindow.ts` | 创建隐藏 BrowserWindow + SSRF 防护 |
| 脚本引擎 | `handlers/thirdparty/engine.ts` | 脚本加载/卸载/生命周期/代理更新 |
| 请求队列 | `handlers/thirdparty/requestQueue.ts` | 基于 Promise 的 IPC 请求队列，分区超时 |
| 脚本工具 | `handlers/thirdparty/scriptUtils.ts` | 注释头解析、zlib 压缩、CRUD |
| 内置源 | `handlers/thirdparty/builtinSources.ts` | 5 平台公开 API 搜索（tx/kw/kg/wy/mg），支持自定义请求头、字段归一化、封面 URL 构建 |
| IPC 处理器 | `handlers/thirdparty/userapiHandlers.ts` | 10 个 IPC 通道 |
| preload | `handlers/thirdparty/renderer/preload.js` | globalThis.lx 注入（完全兼容 lx-music） |
| 宿主页 | `handlers/thirdparty/renderer/user-api.html` | CSP 严格限制的空白 HTML |
| 前端 Store | `sys_vue/store/thirdpartySource.ts` | 源管理/搜索/播放 |

### lx-music 兼容性

preload.js 完全复刻了 lx-music 的 UserAPI 协议，包括：

- `lx.request(url, options, callback)` — HTTP 请求桥（needle 实现）
- `lx.send('inited', { sources })` — 脚本注册
- `lx.on('request', handler)` — 处理 musicUrl/lyric/pic
- `lx.utils.crypto` — AES/RSA/MD5 加解密
- `lx.utils.buffer` / `lx.utils.zlib` — Buffer 和压缩工具
- `lx.currentScriptInfo` — 脚本元信息

社区现有的 lx-music 用户脚本无需修改即可直接运行。
