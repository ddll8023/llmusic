# 系统设置模块开发设计

> 本文档针对 LLMusic 中的系统设置模块，描述该模块的需求、项目内结构与流程、数据库和 API 设计。代码组织见 `doc/项目结构文档.md`，业务定位见 `doc/模块说明文档.md`。

---

## 1. 需求

### 模块目标

系统设置模块管理用户的偏好配置并持久化，解决"用户如何按自己的习惯定制应用行为"这一需求。当前覆盖窗口关闭行为、歌词页动画效果、性能模式、开发者模式、桌面歌词设置与界面布局偏好。

### 功能需求

- 用户可配置窗口关闭行为：退出应用或最小化到托盘
- 用户可选择歌词页动画样式
- 用户可开启性能模式（关闭歌词页装饰性动画，提升低端设备流畅度）
- 用户可开启开发者模式（显示开发者日志入口）
- 用户可控制侧边栏显示/隐藏
- 用户可配置桌面歌词：启用、锁定、字号、单/双行显示、当前行颜色、下一行颜色
- 设置即时生效并持久化，应用重启后恢复

### 非功能需求

- 偏好读写容错：localStorage 读取失败或数据损坏时回退默认值
- 关闭行为需主进程与渲染层一致：经 IPC 同步，启动时以主进程值为准回填
- 设置写入失败静默降级（不影响功能）

### 当前范围与明确不做项

- 设置项当前包括窗口关闭行为、歌词页动画、性能模式、开发者模式、桌面歌词设置与侧边栏显示；播放音量/播放模式随播放状态持久化（归音乐播放模块），不在本模块
- 无设置导入导出、多 profile
- 桌面歌词配置因主进程需要创建窗口，使用 settings 表持久化；其余偏好仍存于渲染层 localStorage

### 与其他模块的职责边界

- 被窗口与 UI 壳（关闭行为、侧边栏、性能模式、开发者模式、桌面歌词窗口消费）、歌词管理（动画样式与性能模式消费）、操作日志（入口控制）依赖
- 关闭行为经 IPC 与主进程窗口关闭逻辑联动
- 桌面歌词设置经 IPC 与主进程桌面歌词窗口管理联动

### 验收标准

- 修改任一设置后立即生效，重启应用保持
- 关闭行为设置为最小化后，关闭窗口隐藏至托盘
- 性能模式开启后歌词页无装饰动画
- 开发者模式开启后侧边栏显示开发者日志入口，关闭后隐藏
- 桌面歌词启用后重启自动恢复窗口，锁定/字号/单双行/颜色设置即时生效并保持
- localStorage 数据损坏时应用以默认值正常启动

## 2. 该项目的模块结构与流程

### 项目级模块关系

```
设置页 / 播放栏 / 桌面歌词窗口 ──> 系统设置（UI store + 桌面歌词 store） ──消费──> 窗口与 UI 壳（关闭行为/侧边栏/播放栏/开发者模式/桌面歌词窗口）
                        │
                        ├──消费──> 歌词管理（动画样式/性能模式/桌面歌词）
                        └──入口控制──> 操作日志（开发者日志页）
```

### 当前代码边界

- 渲染层状态：UI store（设置项读写 + 持久化，含关闭行为与主进程双向同步）、桌面歌词 store（桌面歌词设置状态）
- 渲染层页面：设置页组件（设置项 UI 与交互，不含桌面歌词设置区）；桌面歌词设置面板位于桌面歌词窗口内
- 主进程：窗口关闭行为持有于主进程内存（appState）；桌面歌词配置由桌面歌词窗口模块读写
- 数据访问层：settings 仓库（key-value 存储，JSON 序列化），被桌面歌词配置调用

### 核心业务流程

1. 设置页修改选项 → UI store 更新状态 → 写 localStorage
2. 关闭行为特例：经 IPC 调主进程校验并更新内存 → 成功后写 localStorage；应用启动时反向读取主进程值回填（主进程为权威）
3. 桌面歌词特例：桌面歌词窗口设置面板/播放栏开关修改 → 桌面歌词 store → IPC 调主进程更新配置 → 主进程写 settings 表并应用/广播
4. 启动加载：读取 localStorage 各键（容错回退默认值）→ 初始化状态；桌面歌词 store 从主进程拉取配置
5. 消费方按需读取状态（侧边栏宽度、动画样式、性能模式、开发者模式、桌面歌词配置），变更即时响应

### 数据流和状态流

- 创建：设置页输入 → store 状态 → localStorage（同步写）；桌面歌词输入 → 桌面歌词 store → IPC → settings 表
- 同步：关闭行为双端同步（渲染 → 主进程写入；启动主进程 → 渲染回填）；桌面歌词配置由主进程权威持有并广播
- 失效：localStorage 不可用（隐私模式/满）时仅内存态生效
- 状态：lyricsAnimationStyle（默认 fade）、closeBehavior（默认 exit）、sidebarVisible（默认 true）、performanceMode（默认 false）、developerMode（默认 false）、desktopLyric.enabled/locked/fontSize/doubleLine/currentLineColor/nextLineColor（主进程配置）

### 异常与并发规则

- 设置写入 catch 后仅记录，不阻断交互
- 启动回填以主进程关闭行为为准（避免双端不一致）
- 无效关闭行为值被主进程拒绝并返回错误

### 关键技术选择

- 偏好存 localStorage 而非 SQLite：纯前端偏好、主进程无需感知，读写零 IPC 开销
- 关闭行为例外：必须主进程持有（窗口关闭逻辑在主进程），故走 IPC 同步
- 桌面歌词配置例外：主进程需在启动时创建窗口，故存 settings 表并由主进程持有权威状态

## 3. 数据库的设计

本模块大部分偏好仍存于 localStorage，桌面歌词配置使用 SQLite settings 表：

- 偏好持久化于渲染进程 localStorage（键：closeBehavior、lyricsAnimationStyle、sidebarVisible、performanceMode、developerMode）
- 桌面歌词配置持久化于 settings 表（键：desktopLyric），由主进程读写
- 关闭行为的权威状态在主进程内存（appState.closeWindowBehavior）
- settings 表已由桌面歌词配置调用；其余偏好不新增写入路径
- 数据生命周期：localStorage 随用户数据目录；settings 表随应用用户数据目录；无敏感数据；无删除与备份需求
- 隐私边界：偏好不包含个人信息，不进日志

### 结构变更策略（设计假设）

若后续将更多偏好迁移至 settings 表，需：新增 IPC 读写通道、以 localStorage 为存量迁移源、明确主进程权威项；当前仅桌面歌词配置使用 settings 表。

## 4. API 接口的设计

本模块不提供 HTTP 接口，公开边界为 IPC 通道与渲染层内部状态接口。

### IPC 接口（关闭行为同步）

| 通道 | 调用方向 | 入参 | 返回要点 |
|---|---|---|---|
| set-close-behavior | 渲染 → 主进程 | behavior（exit/minimize） | `{ behavior }`；无效值返回错误 |
| get-close-behavior | 渲染 → 主进程 | 无 | `{ behavior }`，启动回填用 |

### IPC 接口（桌面歌词配置）

| 通道 | 调用方向 | 入参 | 返回要点 |
|---|---|---|---|
| desktop-lyric-get-state | 渲染 → 主进程 | 无 | 当前桌面歌词配置 |
| desktop-lyric-set-enabled | 渲染 → 主进程 | enabled | 创建/销毁桌面歌词窗口并持久化 |
| desktop-lyric-update-config | 渲染/桌面窗口 → 主进程 | locked/fontSize/alwaysOnTop 等 | 更新配置、应用并广播 |
| desktop-lyric-config-changed | 主进程 → 渲染 | 最新配置 | 桌面歌词窗口/播放栏状态同步 |

### 渲染层内部接口

| 入口 | 说明 |
|---|---|
| setLyricsAnimationStyle / setPerformanceMode / setDeveloperMode / toggleSidebar 等 | 设置读写 + localStorage 持久化 |
| initCloseBehavior | 启动时以主进程值为准回填 |
| desktopLyricsStore.init / setEnabled / setLocked / setAlwaysOnTop / setFontSize / setDoubleLine / setCurrentLineColor / setNextLineColor | 桌面歌词配置拉取与 IPC 写入 |

### 错误边界

- 无效关闭行为由主进程拒绝（仅 exit/minimize 合法）
- 本地存储读写失败静默降级，不影响功能
- IPC 调用失败不阻断应用启动（默认值兜底）
- 桌面歌词配置读写失败时使用默认配置，不阻断主应用

### 前端调用关系

- 设置页组件消费 UI store；桌面歌词窗口设置面板与播放栏消费桌面歌词 store；歌词页、播放控制栏与侧边栏开发者日志入口读取相关设置项
- 新增设置项遵循既有模式：store 状态 + 持久化 + 消费方响应式读取；主进程需要感知的设置（如桌面歌词）额外走 IPC 同步
